# Alchemy of Art History (Pigments Database) — REST API (ЛР3)

Документация к веб-сервису Лабораторной работы №3 по предмету «Разработка веб-приложений».

---

## 1. Таблицы Базы Данных (PostgreSQL)

### 1. Таблица `pigments` (Образцы пигментов)
| Поле | Тип данных | Описание | Constraints |
|---|---|---|---|
| `id` | `SERIAL / uint` | Уникальный идентификатор пигмента | `PRIMARY KEY` |
| `name` | `VARCHAR(100)` | Название пигмента | `NOT NULL` |
| `short_description` | `TEXT` | Краткое экспертное описание | |
| `status` | `VARCHAR(20)` | Статус записи (`черновик`, `опубликован`, `удалён`) | `DEFAULT 'черновик'` |
| `image_url` | `VARCHAR(255)` | Имя/путь файла изображения в MinIO | |
| `video_url` | `VARCHAR(255)` | Имя/путь файла видео в MinIO | |
| `reflection` | `DECIMAL(5,2)` | Спектральный коэффициент отражения (R) | |
| `absorption` | `DECIMAL(5,2)` | Спектральный коэффициент поглощения (A) | |
| `created_at` | `TIMESTAMP` | Дата и время создания черновика | `NOT NULL` |
| `formed_at` | `TIMESTAMP` | Дата и время публикации | |
| `creator_id` | `INT / uint` | Идентификатор пользователя-создателя | `FOREIGN KEY (users.id)` |

### 2. Таблица `users` (Пользователи / Эксперты)
| Поле | Тип данных | Описание | Constraints |
|---|---|---|---|

### 3. Таблица `likes` (Лайки пользователей)
| Поле | Тип данных | Описание | Constraints |
|---|---|---|---|
| `id` | `SERIAL / uint` | Уникальный идентификатор лайка | `PRIMARY KEY` |

## 2. Доменные HTTP Методы и REST API Endpoints

### 📁 Домен Услуги (Pigments)

#### 1. `GET /api/pigments`
* **Описание**: Список опубликованных пигментов с фильтрацией.
* **Параметры**: `?filter=0.5` (фильтрация по поглощению `absorption <= filter`).
* **Ответ**: Массив объектов пигментов. Для каждого объекта вычисляется поле `is_creator` (`1` если создатель = текущий пользователь, иначе `0`).

#### 2. `GET /api/pigments/feed`
* **Описание**: Лента только опубликованных пигментов.
* **Ответ**: Массив опубликованных пигментов с подсчитанным `likes_count`.

#### 3. `GET /api/pigments/draft`
* **Описание**: Получение черновика текущего пользователя.
* **Особенности**: ID в URL не указывается. Возвращает не более 1 записи (`status = 'черновик'`).

#### 4. `POST /api/pigments`
* **Описание**: Создание черновика + файлов картинки и видео в MinIO SDK.
* **Формат**: `multipart/form-data` (поля `name`, `short_description`, `image`, `video`).
* **Особенности**: Имена файлов генерируются на латинице (`img_...png`, `vid_...mp4`) и сохраняются в MinIO.

#### 5. `PUT /api/pigments/:id/publish`
* **Описание**: Публикация черновика (смена статуса на `опубликован`).
* **Тело**: JSON (`short_description`, `reflection`, `absorption`).
* **Особенности**: Проставляет текущее время `formed_at`. Возвратить в черновик нельзя.

#### 6. `DELETE /api/pigments/:id`
* **Описание**: Soft Delete (логическое удаление, `status = 'удалён'`).
* **Особенности**: Выполняется только для услуг текущего пользователя. Записи со статусом `удалён` клиенту не отдаются.

#### 7. `POST /api/pigments/:id/like`
* **Описание**: Управление лайком от текущего пользователя.
* **Параметры**: `?value=1` (поставить лайк) или `?value=0` (отменить лайк).

---

### 📁 Домен Пользователь (Users)

#### 8. `POST /api/users/register`
* **Описание**: Регистрация нового пользователя.
* **Тело**: JSON (`name`, `login`, `password`).

#### 9. `POST /api/users/login`
* **Описание**: Аутентификация пользователя (заглушка для ЛР4).
* **Ответ**: JSON с токеном авторизации.

#### 10. `POST /api/users/logout`
* **Описание**: Деавторизация пользователя (заглушка для ЛР4).

#### 11. `GET /api/users/:id/pigments`
* **Описание**: Вложенная сериализация профиля пользователя и всех созданных им пигментов.
* **Ответ**: Объект `user` + массив `pigments: [...]`.
